# Ясный английский

Приложение для изучения английского для русскоговорящих: курс с нуля, тест уровня, карточки с интервальными повторениями, грамматика, перевод, чтение, произношение и работа над ошибками.

- Веб-версия (с ИИ и синхронизацией): страница на claude.ai.
- `index.html` — само приложение.
- `android/` — оболочка для Android (WebView + синтез речи), сборка: `android/build.sh`.
- `ios/` — оболочка для iOS (WKWebView + AVSpeechSynthesizer), проект генерируется XcodeGen.
- `.github/workflows/build.yml` — сборка IPA (без подписи) и APK в GitHub Actions при каждом push в `main`.

## Как получить файлы
Actions → последний запуск «Сборка приложений» → Artifacts:
- `YasnyEnglish-iOS-unsigned-ipa` — IPA без подписи, подписывается своим сертификатом (например, через eSign);
- `YasnyEnglish-Android-apk` — готовый APK.

## Подпись APK
Чтобы обновления ставились поверх старой версии, добавь секреты репозитория:
`ANDROID_KEYSTORE_B64` (keystore в base64) и `ANDROID_KEYSTORE_PASS` (пароль). Без них при каждой сборке создаётся новый ключ.
