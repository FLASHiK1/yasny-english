# Ясный английский — передача проекта в новый чат

Приложение для изучения английского «с нуля до B2» для русскоязычной ученицы (девушка владельца). Владелец — FLASHiK1. Общение — по-русски.

## Где что лежит

- Репозиторий: https://github.com/FLASHiK1/yasny-english (ветка `main`)
- Telegram-версия (GitHub Pages): https://flashik1.github.io/yasny-english/ — открывается кнопкой «Начнём» в боте владельца
- Веб-версия (артефакт claude.ai): https://claude.ai/artifact/BDapLLGZv3Ce7zMskqcAPu — публикуется из `index.html`, у артефакта включены возможности `sample` (ИИ), `db` и `user` (синхронизация через аккаунт claude.ai)

## Структура

- `index.html` — всё приложение одним файлом (~720 КБ): данные (слова, правила, тексты, диалоги, вопросы), логика, стили.
- `tg/make_tg.py` — оборачивает `index.html` для Telegram Mini App: SDK Telegram, тема, кнопка «Назад», синхронизация через `Telegram.WebApp.CloudStorage` (состояние кусками по 3800 символов, ключи `st_0…`, `st_meta`).
- `.github/workflows/pages.yml` — при push в `main` собирает Telegram-версию и публикует на Pages.
- `.github/workflows/build.yml` — сборка APK и IPA **только вручную** (Actions → «Сборка приложений» → Run workflow).
- `android/` — WebView-обёртка без Gradle (aapt2 + javac + d8 + apksigner, `build.sh`), мост `AndroidTTS` (speak, speakP с pitch, stop, распознавание речи, напоминания, shareToGemini), событие конца речи `window.__ttsDone`. `make_assets.py` встраивает `index.html` в ассеты.
- `ios/` — WKWebView-обёртка (XcodeGen), IPA без подписи, владелец подписывает сам через esign.
- `packs/` — тематические наборы слов (JSON); встроены и в `index.html`.

## Как устроен код (важно для правок)

- Глобальное состояние `S` хранится в localStorage `yasny-eng-v1`; `save()` пишет его. Слияние двух состояний — `mergeState(a,b)`.
- Маршруты — hash (`#today`, `#learn`, `#path`, `#mistakes` и т. д.), список `ROUTES` и объект вызова в `route()`; хлебные крошки — `CRUMB`; вкладки — `TABS`.
- Новые функции добавлены модулями **в конце скрипта**, перед строкой `autoPacks();applyPacks();migrateRrev();applyFreeze();`, и подключаются обёртками существующих функций (`const _x=x; x=function(){...}`). Так сделаны: «Мой путь», диалоги, итоги недели, контрольные, разговор с Ясиком, «10 минут», «Мои слова»/«Настройки»/«Достижения», карточки слов, тест с вводным экраном, темы, выбор голоса.
- Маскот — Ясик: `yasik(mood,size,{anim})`, `yasay(mood,html,size)`.
- Повтор трудного (бывшие «Ошибки»): `mistake(k,ref,ok,user,meta)`, задания строит `taskOf(m)`.
- Проверка ответов: `check()` / `classifyAnswer()` — отличают опечатку от ошибки по теме.
- ИИ: в веб-версии через `window.claude.use("sample")`; в приложении и Telegram — ключ Gemini пользователя (`window.__NATIVE_APP=true`).

## Что сделано (кратко)

Курс с нуля (30 уроков), карточки с интервальным повторением, грамматика 27 правил + справочник, повтор трудного, тест уровня (вводный экран, ответы A–D), «Мой путь» (68+ шагов по уровням с контрольными), 18 диалогов на слух (два голоса), 29 текстов, перевод фраз, диктант, разговор с Ясиком (40 вопросов, проверка без ИИ), режим «10 минут», итоги недели, достижения, темы оформления (6 цветов + светлая/тёмная), выбор голоса и скорости, карточки слов вместо набора текста (A0–A1 по умолчанию), Telegram-версия с облачной синхронизацией.

## Следующие задачи

1. **Firebase** (бесплатный план). Нужно: проект, Authentication → Anonymous, Firestore (production) с правилами ниже, веб-приложение → взять `apiKey` и `projectId`. Работать через REST (Identity Toolkit `accounts:signUp` для анонимного входа + Firestore REST), без SDK. Веб-артефакт claude.ai до Firebase не достучится (CSP), только Telegram-версия и приложения.

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       match /sync/{id} {
         allow read, write: if request.auth != null && id.size() >= 16;
       }
       match /transfer/{code} {
         allow read, write: if request.auth != null && code.size() >= 6 && code.size() <= 12;
       }
       match /rooms/{room}/members/{pid} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```

2. **Перенос по короткому коду**: устройство A кладёт состояние в `transfer/{6 символов}` (срок 15 минут), устройство B вводит код и забирает; слияние через `mergeState`. Кнопки — в «Профиль → Настройки → Перенос прогресса» (сейчас там длинный код `YE1:`).
3. **Вход через Telegram в APK**: кнопка открывает `https://t.me/<бот>?startapp=link_<код>`; Telegram-версия видит `start_param`, создаёт/берёт секрет синхронизации (хранит в CloudStorage) и пишет его в `transfer/{код}`; APK забирает секрет, дальше оба синхронизируются через `sync/{секрет}`. Нужно: username бота и в @BotFather → Bot Settings → Configure Mini App → Enable, адрес Pages.
4. **Соревнование**: код пары, очки за неделю в `rooms/{код}/members/{id}` (имя, очки недели, серия, слова), экран с таблицей, серия побед, вызовы («кто первым 200 очков»).
5. Потом, по команде владельца: новый APK/IPA (в нём появятся выбор голоса через мост Android и вход через Telegram).
